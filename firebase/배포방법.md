# 프로호구 매니저 – Firebase 배포 방법

이 폴더(`firebase/`)를 통째로 PC에 풀고 아래 순서대로 하면 됩니다. Node.js가 필요해요(https://nodejs.org 에서 LTS 설치).

1. 명령 프롬프트(또는 터미널)를 열고 Firebase 도구 설치
   `npm install -g firebase-tools`
2. 로그인 (브라우저가 열리면 Firebase 콘솔과 같은 Google 계정으로)
   `firebase login`
3. 이 폴더로 이동한 뒤 배포
   `cd 압축푼경로\firebase`
   `firebase deploy`
   → 웹사이트(Hosting)와 Firestore 보안 규칙이 함께 올라갑니다.
4. 끝나면 주소가 나와요: https://baseball-manager-1aaeb.web.app
   이 주소를 친구들에게 보내면 됩니다.

## 처음 한 번 확인할 것
- Firebase 콘솔 → Authentication → 로그인 방법 → Google "사용 설정됨" (완료)
- Firebase 콘솔 → Firestore Database 가 만들어져 있어야 해요(이미 규칙 탭을 보셨으니 완료).
- Authentication → 설정 → 승인된 도메인에 `baseball-manager-1aaeb.web.app`, `baseball-manager-1aaeb.firebaseapp.com` 이 있는지 (기본으로 들어 있어요).

## 게임에서 친구와 하는 법
1. "친구 리그" 탭 → Google로 로그인
2. 한 명이 리그를 만들고 6자리 코드를 단톡방에 공유 → 나머지는 코드로 참가
3. 각자 라인업을 짠 뒤 "내 라인업 등록/갱신"
4. 순위표에서 친구 팀 옆 "직접 지휘"(작전 직접) 또는 "결과만"으로 도전 → 결과가 리그 순위에 쌓여요.

## 무료(Spark) 요금제 한도
하루 읽기 5만 / 쓰기 2만 건, Hosting 전송 월 10GB 정도라 친구 몇 명이 하기엔 충분해요.
카드 데이터(cards.json 2.9MB)와 사진은 첫 접속 때 한 번 내려받고 브라우저가 캐시해요.
